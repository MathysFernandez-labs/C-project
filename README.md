# Advanced Data Structures — Comparative Study in C

This repository contains the generic C implementation and experimental performance analysis of four fundamental data structures, developed as part of the **Advanced Data Structures** course (L3 S5 Computer Science — La Rochelle Université).

## Project Objectives

The main goal is to implement generic data structures (`void *`) and experimentally compare the time complexities of **insertion**, **search**, and **deletion** operations (ranging from $N = 100$ to $N = 10,000$ elements with a step of 100) across multiple data types (integers and character strings) for:
* **Hash Table**
* **Binary Search Tree (BST)**
* **AVL Tree** 
* **Red-Black Tree (Bicolor Tree)**
